# Changelog

## v1.0.2
- Fixed lightweight item weights not being applied automatically when logging into a character.
- Inventory weight now recalculates when the local player spawns.

## v1.0.1
- Fixed feather icons failing to load when installed through Thunderstore or r2modman.
- Feather assets are now loaded relative to the plugin DLL.

## v1.0.0
- Initial public release.
- Configurable lightweight inventory rows and weight multiplier.
- Feather indicators for lightweight slots.
- Support for expanded inventories and SeneaL UI.
- Client-side functionality without a required server installation.
